LandSight: Real-Time Climate-Driven Landslide Detection and Forecasting

LandSight is a machine learning–based system designed to predict and detect landslides by analyzing real-time satellite and climate data. The project focuses on improving the accuracy, speed, and spatial coverage of existing global landslide forecasting tools.

Unlike traditional systems that rely only on rainfall thresholds or delayed imagery analysis, LandSight combines multiple data sources — including topographic, hydrological, and vegetation parameters — and feeds them into a hybrid CNN-LSTM model. This allows it to capture both the spatial and temporal patterns that often precede landslides.

The system is built to handle real-time data from satellites such as Sentinel, Landsat, and IMERG, and integrates them with local terrain information to generate dynamic landslide susceptibility maps. Using Microsoft’s Aurora acceleration framework, LandSight can deliver faster predictions with lower latency, making it suitable for real-world disaster response and early warning applications.

LandSight’s broader goal is to contribute to global disaster resilience by providing an open, scalable, and adaptable platform for landslide forecasting — one that can eventually be deployed at local, national, or global levels.
